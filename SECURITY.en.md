# Security policy

[Русский](SECURITY.md) · **English**

Do not publish real infobase paths, credentials, customer configuration sources, customer data, `.cf`, `.cfe`, or `1Cv8.1CD` files in an Issue.

Report a vulnerability through [Private vulnerability reporting](https://github.com/Muredsa/1C-Enterprise-Agent-Toolkit/security/advisories/new). Prepare a minimal reproduction with a synthetic disposable infobase and do not disclose exploitable details publicly before a fix.

The project is designed for isolated copies. Treat `--allow-live-base` and `--allow-existing` as high-risk overrides requiring an explicit human decision.

The current stable version is supported. Security fixes are published as patch releases.
