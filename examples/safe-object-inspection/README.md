# Безопасная проверка объекта любой конфигурации 1С

**Русский** · [English](README.en.md)

Этот универсальный пример создаёт одноразовую копию файловой базы, выборочно выгружает один явно указанный объект метаданных и гарантированно удаляет рабочую сессию в блоке `finally`.

```powershell
.\examples\safe-object-inspection\workflow.ps1 `
  -BaseFile "C:\Bases\MyConfiguration" `
  -Object "Catalog.Номенклатура" `
  -User "Администратор"
```

Сценарий не знает состав конфигурации заранее: полное имя объекта передаётся через `-Object`. Это может быть объект типовой, отраслевой или полностью самописной конфигурации, например `Document.ЗаказПокупателя` или `InformationRegister.МойРегистр`.

Сценарий печатает JSON выгрузки и краткий список созданных файлов до очистки. Исходный файл `1Cv8.1CD` не изменяется.

> [!CAUTION]
> Не добавляйте к примеру `--no-sandbox` или `--allow-live-base`: он специально предназначен только для изолированной копии файловой базы.

УНФ была одной из сред интеграционного тестирования проекта, но не является требованием или ограничением этого сценария.
