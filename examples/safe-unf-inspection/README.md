# Безопасная проверка одного объекта УНФ

**Русский** · [English](README.en.md)

Этот пример создаёт одноразовую копию файловой базы, выборочно выгружает один объект метаданных и гарантированно удаляет рабочую сессию в блоке `finally`.

```powershell
.\examples\safe-unf-inspection\workflow.ps1 `
  -BaseFile "C:\Bases\UNF" `
  -Object "Catalog.Номенклатура" `
  -User "Администратор"
```

Сценарий печатает JSON выгрузки и краткий список созданных файлов до очистки. Исходный файл `1Cv8.1CD` не изменяется.

Для другого объекта передайте его полное имя метаданных, например `Document.ЗаказПокупателя`. Для другой конфигурации используется тот же процесс.

> [!CAUTION]
> Не добавляйте к примеру `--no-sandbox` или `--allow-live-base`: он специально предназначен только для изолированной копии файловой базы.
